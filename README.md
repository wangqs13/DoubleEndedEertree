# Double-Ended Eertree

This repository provides a linear-time implementation of the "double-ended eertree" data structure based on [WYZ25]. 

[WYZ25] [Qisheng Wang](https://scholar.google.com/citations?user=t9NllbcAAAAJ), [Ming Yang](https://orcid.org/0000-0003-2756-8264), and [Xinrui Zhu](https://orcid.org/0009-0006-6849-9110). Double-ended palindromic trees in linear time. *Information and Computation*, 307: 105379, 2025. [doi:10.1016/j.ic.2025.105379](https://doi.org/10.1016/j.ic.2025.105379). [arXiv:2210.02292](https://arxiv.org/abs/2210.02292).

## Useful Links
